# PART 3/4 - MODEL ARCHITECTURE + SEARCH SPACE (merged from buoc_09_dcnv2.py)
DCNv2 model -- Deep & Cross Network version 2 (Deep Network combined with Cross Network).
The model consists of TWO parallel branches that run side by side then get concatenated:
  a) CROSS NETWORK: creates "feature interactions" EXPLICITLY. This is the key
     point that makes DCNv2 well suited to answering counter-argument #4 (about
     interactions between variables such as w/cm, fly ash, and curing temperature):
     the architecture learns the interaction order (cross-order) automatically instead of
     relying only on post-hoc SHAP/PDP.
  b) DEEP NETWORK: a regular MLP that learns higher-order non-linear
     relationships that the cross branch doesn't fully capture.
The two branches are combined in parallel (parallel structure) then passed through the output layer.
2. CROSS BRANCH FORMULA (CrossLayerV2)
Each cross layer computes:
        x_{l+1} = x_0 (elementwise-mult) (W_l . x_l + b_l) + x_l
where:
  - x_0   : the ORIGINAL feature vector (initial input), kept unchanged across all layers.
  - x_l   : the output of cross layer l.
  - W_l   : a d x d weight MATRIX (this is what differs in "v2" compared to the original
            DCN which uses a vector). The matrix gives much stronger interaction
            representational power than a vector.
  - elementwise-mult : element-wise multiplication.
  - + x_l : skip connection -- helps stabilize training.
Meaning: after l layers, the model can represent feature interactions up to order
(l+1). For example 2 cross layers capture 3rd-order interactions between input variables.
3. OVERALL ARCHITECTURE (parallel)
   n_cross cross layers           deep_layers FC layers
   (keeps size in_dim)     (FC -> BN -> ReLU -> Dropout)
              Head: FC(-> 1)   = predicted value (regression)
4. HYPERPARAMETERS (Optuna-optimized)
  - n_cross (1-3)     : number of cross layers -> maximum feature interaction order.
  - deep_h (64-256)   : number of units per layer of the deep branch.
  - deep_layers (1-3) : number of layers of the deep branch.
  - dropout (0.05-0.3): fights overfitting in the deep branch.
  - lr, wd            : learning rate and weight decay for AdamW.
  - Models feature interactions EXPLICITLY (interpretable, addresses counter-argument #4).
  - The cross branch has few parameters and is stable; the deep branch adds higher-order non-linearity.
  - Usually strong on tabular data with many interactions between variables.
  - More components than a plain MLP -> more hyperparameters to tune.
  - The d x d matrix in each cross layer is more expensive than a vector (DCN v1) when in_dim is large.
